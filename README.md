# YGT Executive Limo

Initial Next.js website for YGT Executive Limo.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

Upload the project files to the existing `ygt-executive-limo` GitHub repository.
Vercel will detect Next.js and deploy automatically.

## Current booking behavior

The first version collects trip details and opens the user's email client for manual confirmation.
Instant pricing, Stripe payment and Limo Anywhere integration are intentionally left for the next phase.
